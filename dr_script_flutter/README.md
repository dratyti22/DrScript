# Dr Script Flutter IDE

Полнофункциональная IDE для языка программирования Dr Script, созданная на Flutter.

## Возможности

🎨 **Современный интерфейс**
- Темная и светлая темы
- Настраиваемый размер шрифта
- Профессиональный дизайн в стиле VS Code

📝 **Редактор кода**
- Подсветка синтаксиса для Dr Script
- Нумерация строк
- Автоматические отступы
- Поддержка комментариев

📁 **Файловый менеджер**
- Открытие и сохранение файлов .dr
- История недавних файлов
- Информация о файле (строки, символы)

🚀 **Выполнение кода**
- Кнопка запуска с индикатором прогресса
- Консоль вывода с прокруткой
- Симуляция выполнения Dr Script

⚙️ **Настройки**
- Изменение размера шрифта (10-24px)
- Переключение тем
- Сохранение настроек

## Установка и запуск

1. Убедитесь, что Flutter установлен:
```bash
flutter --version
```

2. Установите зависимости:
```bash
flutter pub get
```

3. Запустите приложение:
```bash
flutter run
```

## Зависимости

- `google_fonts` - Шрифт JetBrains Mono
- `code_text_field` - Редактор кода с подсветкой
- `highlight` - Подсветка синтаксиса
- `file_picker` - Работа с файлами
- `shared_preferences` - Сохранение настроек
- `path_provider` - Доступ к файловой системе

## Структура проекта

```
lib/
├── main.dart                 # Основное приложение
├── dr_script_highlighter.dart # Подсветка синтаксиса Dr Script
examples/
├── demo.dr                   # Демонстрационный код
```

## Использование

1. **Открытие файла**: Нажмите иконку папки в панели инструментов
2. **Сохранение**: Нажмите иконку сохранения
3. **Запуск кода**: Нажмите зеленую кнопку "Запустить"
4. **Настройки**: Нажмите иконку шестеренки

## Поддерживаемые конструкции Dr Script

- Переменные: `var x = 10;`
- Функции: `function name() { }`
- Условия: `if/else`
- Циклы: `for`, `while`
- Комментарии: `//` и `/* */`
- Встроенные функции: `print()`, `input()`

## Скриншоты

IDE включает:
- Файловый проводник слева
- Редактор кода в центре с подсветкой синтаксиса
- Консоль вывода справа
- Панель инструментов сверху

## Разработка

Для добавления новых функций:

1. Обновите `dr_script_highlighter.dart` для новых ключевых слов
2. Модифицируйте `main.dart` для новых возможностей UI
3. Добавьте примеры в папку `examples/`
