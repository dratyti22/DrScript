# Dr Script IDE - Веб-версия

Простая IDE для языка программирования Dr Script, работающая в браузере.

## 🚀 Быстрый запуск

### Windows:
1. Убедитесь, что установлен Python 3
2. Запустите `run.bat`
3. Браузер автоматически откроется с IDE

### Linux/Mac:
1. Убедитесь, что установлен Python 3
2. Запустите `./run.sh`
3. Браузер автоматически откроется с IDE

### Альтернативный способ:
```bash
python3 server.py
```
Затем откройте http://localhost:8000 в браузере

## 📝 Возможности

- ✅ Редактор кода с подсветкой синтаксиса
- ✅ Выполнение Dr Script кода в браузере
- ✅ Примеры кода (переменные, условия, циклы, функции)
- ✅ Вывод результатов выполнения
- ✅ Обработка ошибок

## 🔬 Язык Dr Script

### Синтаксис:
- `ver x = 1;` - мутабельная переменная
- `var y = 4;` - немутабельная переменная  
- `print(x);` - вывод значения
- `if x > y { ... } else { ... }` - условия
- `while x < 10 { ... }` - циклы
- `fun add(a, b) { return a + b; }` - функции

### Операторы:
- Арифметические: `+`, `-`, `*`, `/`, `%`
- Сравнения: `<`, `<=`, `>`, `>=`, `==`, `!=`
- Префиксные/постфиксные: `++x`, `x++`, `--x`, `x--`

## 📁 Структура проекта

- `index.html` - веб-интерфейс IDE
- `pkg/` - скомпилированный WebAssembly модуль
- `server.py` - локальный веб-сервер
- `run.bat` / `run.sh` - скрипты запуска

## 🛠 Технологии

- **Rust** - основной язык интерпретатора
- **WebAssembly** - выполнение Rust кода в браузере
- **HTML/CSS/JavaScript** - веб-интерфейс
- **Python** - локальный сервер для разработки
