# Dr Script

Простой язык программирования с минималистичным синтаксисом.

## Синтаксис

### Переменные
```dr
ver x = 1;        // мутабельная переменная
var y = 4;      // немутабельная переменная
```

### Вывод
```dr
print(x + y);
```

## Расширение файлов
`.dr`

## Пример программы
```dr
ver x = 1;
var y = 4;
print(x + y);
```
