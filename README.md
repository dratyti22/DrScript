# Dr Script

Простой язык программирования с минималистичным синтаксисом.

## Синтаксис

### Переменные
```dr
ver x = 1;        // мутабельная переменная
var y = 4;      // немутабельная переменная
```

### Операторы сравнений
```
< <= >= == !=
```

### Условия
```dr
var x = 5;
var y = 10;

if x>y {
    print(1);
}
else {
    print(2); // будет вывод 2
}
if x>y {
    print(3);
}
```


### Вывод
```dr
print(x + y);
```

## Расширение файлов
`.dr`

## Пример программы
```dr
ver x = 1;

```
