# Dr Script

Простой язык программирования с минималистичным синтаксисом.

## Расширение файлов
`.dr`

## Синтаксис

### Вывод Информации
```dr
print(x + y);
```

### Переменные
```dr
ver x = 1;        // мутабельная переменная
var y = 4;      // немутабельная переменная
```

### Операторы сравнений
```
< <= >= == !=
```

### Префиксные и постфиксные операторы
```dr
ver x = 5;
print(++x);  // префикс: сначала увеличивает, потом возвращает (6)
print(x++);  // постфикс: сначала возвращает, потом увеличивает (6, x становится 7)
print(--x);  // префикс: сначала уменьшает, потом возвращает (6)
print(x--);  // постфикс: сначала возвращает, потом уменьшает (6, x становится 5)
```

### Условия
```dr
var x = 5;
var y = 10;

if x>y {
    print(1);
}
else {
    print(2); // будет вывод 2
}
if x>y {
    print(3);
}
```

### Циклы
#### While
```
ver x = 1;
var y = 4;

while x<y {
    print(x);
    x = x +1;
}
```
##### Вывод:
```dr
1
2
3
```
#### For
```dr
ver x = 1;
var y = 4;

for (i=0;i<4;i++) {
    print(x);
}
```
##### Вывод
```dr 
1
1
1
1
```
